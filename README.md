# LAVA DASH

Браузерный 3D-раннер для ресторана **«На LAVA'ШЕ»** (https://nalavashe-vl.ru/).
Беги по закатной улице, собирай шаурму, бургеры, фри и напитки, уворачивайся от
городских препятствий и ставь рекорд.

Сделано на **Three.js + Vite**, без Phaser и без 2D-подмены: весь мир, персонаж,
препятствия и еда — настоящая 3D-геометрия. Текстуры и звук генерируются в
браузере, внешние ассеты не нужны.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
npm run preview  # локальный просмотр сборки
```

## Автономная версия без сервера

```bash
npm run build:standalone
```

Скрипт собирает всё (Three.js, игру, CSS) в один файл:

- **`lava-dash-standalone.html`** — откройте двойным щелчком, работает через `file://` без сервера и интернета (ссылки на сайт ресторана, конечно, потребуют сети);
- `dist-standalone/index.html` — та же сборка для загрузки на хостинг как обычная статическая страница.

В автономной версии нет ES-модулей, внешних скриптов, шрифтов и картинок: только один HTML с встроенными `<style>` и `<script>`.

## Управление

| Действие | Компьютер | Телефон |
| --- | --- | --- |
| Влево | `A` / `←` | кнопка ◀ или свайп влево |
| Вправо | `D` / `→` | кнопка ▶ или свайп вправо |
| Прыжок | `W` / `↑` / `Space` | кнопка ▲, свайп вверх или тап |
| Подкат | `S` / `↓` | кнопка ▼, свайп вниз |
| Пауза | `P` / `Esc` | кнопка паузы в HUD |
| Звук | `M` | иконка динамика |

## Важное про боковое движение

Перестроение между полосами сделано не телепортом, а **критически
задемпфированной пружиной** (`src/game/Player.js`):

```js
const accel = (targetX - x) * 112 - vx * 21;
vx += accel * dt;
x += vx * dt;
```

Из-за этого персонаж плавно набирает боковую скорость, мягко тормозит у целевой
полосы и никогда не «перескакивает» мгновенно. Дополнительно:

- корпус наклоняется в сторону движения (`pose.rotation.z`) и слегка доворачивает
  в поворот (`pose.rotation.y`);
- камера догоняет игрока с запаздыванием, а не копирует его позицию;
- быстрое переключение полос на полпути не сбрасывает скорость, поэтому нет
  рывка при смене решения.

## Структура

```
src/
  main.js                 точка входа
  style.css               весь интерфейс, адаптив, сенсорные кнопки
  game/
    Game.js               состояния, скорость, спавн, камера, очки
    Player.js             модель шаурмы, анимации, плавное движение
    World.js              бесконечная улица, дома, вывески, фонари
    Obstacles.js          конусы, барьеры, машины, контейнеры, перекладины
    Collectibles.js       шаурма, бургер, фри, напиток, бонус
    Collision.js          честные AABB-проверки по X/Z/высоте
    Controls.js           клавиатура, свайпы, сенсорные кнопки
    UI.js                 экраны, HUD, пауза, финал, «как играть»
    Audio.js              WebAudio: музыка и эффекты без файлов
    Effects.js            частицы и вспышки
    textures.js           процедурные текстуры (лаваш, фасады, вывески)
public/assets/            favicon и запасной логотип
```

## Замена маскота на GLB

Персонаж собран в `Player._buildBody()` из примитивов Three.js. Чтобы подключить
готовую модель ресторана, загрузите GLB через `GLTFLoader`, добавьте её в
`this.model` (внутри `this.flip`), а процедурную геометрию оставьте как fallback
до загрузки. Вся игровая логика (коллайдер, прыжок, подкат, полосы) от модели не
зависит — она работает через `player.x`, `player.y` и `player.getCollider()`.

## Рекорды и промо

- Лучший результат хранится в `localStorage` (`lava-dash-best`).
- Звук запоминается в `lava-dash-muted`.
- Реальные скидки и промокоды не выдумываются. Ссылки ведут на
  https://nalavashe-vl.ru/. Проверяемые сервером промокоды можно добавить позже:
  экран финала и HUD уже отделены от игровой логики.
